Balloon Pop Challenge

Game Instructions

Game Goal

The goal of the game is to click balloons before they float off the top of the screen. Each balloon popped increases your score.

Some balloons may be bonus balloons and give more points than normal balloons.

How to Play

  1. Enter your player name on the launcher page.
  2. Select the difficulty level.
  3. Select the game length.
  4. Choose a theme such as Classic, Party, or Space.
  5. Select optional features such as sound, double points, or bonus balloons.
  6. Click Open Game Window.
  7. In the game window, click Start Game.
  8. Click balloons as they rise into the sky.
  9. Try to pop as many balloons as possible before time runs out.

Difficulty Levels

  • Easy: balloons rise slowly, are larger, and appear less often
  • Medium: moderate speed, size, and spawn rate
  • Hard: balloons rise faster, are smaller, and appear more often

Buttons in the Game Window

  • Start Game starts a new game
  • Pause / Resume pauses or resumes the game
  • Save Session stores the current game state
  • Load Session restores a saved game
  • Reset Game clears the current game
  • Back to Settings closes the game window and returns to the launcher

Scoring

  • Each normal balloon adds points
  • Bonus balloons add more points
  • If Double points is enabled, all successful pops score double
  • Balloons that escape off the top of the screen count as missed
  • The game ends when the timer reaches zero

Tips

  • Watch all parts of the screen, not just the middle
  • React quickly to bonus balloons because they are worth more
  • On hard mode, smaller balloons require more accurate clicking
